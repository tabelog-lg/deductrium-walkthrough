## isProp/isSet/isContr
- 第一道题$\P{x:\mathrm{True}}\P{y:\mathrm{True}}\eqv{(\eqs{x}{y})}{\mathrm{True}}$
```txt
intro x
intro y
expand eqv
ex
intro h
exact true
simpl
case
ex
intro h
destruct y
destruct x
rfl
simpl
intro x'
destruct x
destruct x'
rfl
case
intro h
destruct y
destruct x
rfl
intro x'
destruct x'
rfl
qed
```
- 解锁谓词$\rm{isProp}$
- $\prop{a}$展开的结果为$\P{x:a}\P{y:a}\eqs{x}{y}$
- 下一题:$\prop{\True}$
```txt
expand isProp 
intro x 
intro y 
destruct x 
destruct y 
rfl 
qed
```
- 解锁谓词$\rm{isSet}$
- $\set{a}$展开的结果为$\P{x:a}\P{y:a}\prop{(\eqs{x}{y})}$
  (真是不错的套娃)
  
  下一题$\P{a:\U} (\prop{a}) \ra a \ra (\eqv{a}{\rm{True})}$
```proof
intro a
intro h
intro h'
expand eqv
ex
intro h''
exact true
simpl
case
ex
intro h''
apply h'
simpl
intro x
apply h x h'
case
intro h''
apply h'
intro x
destruct x
rfl
qed
```
