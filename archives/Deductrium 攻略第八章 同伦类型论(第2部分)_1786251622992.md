## I
- 区间类型$\I$有两个端点$\i{0}$,$\i{1}$以及连接它们的一条路径$\seg$
- $\seg$的类型是$\eqs{\i{0}}{\i{1}}$
- $\eqs{\i{1}}{\i{0}}$这题很水直接$\inveq{\seg}$就行
- $\P{x:\I}\eqs{x}{\i{0}}$也很水 
- $\eqv{\I}{\True}$这题稍微有点意思
```txt
expand eqv 
ex 
intro h 
exact true 
simpl 
case 
ex 
intro h 
apply 0I 
simpl 
intro x 
destruct x 
rfl 
apply inveq segI 
eq 
eq 
rfl 
case 
intro h 
apply 0I 
intro x 
destruct x 
rfl 
qed
```
- 这说明了$\I$名义上有两个构造子,但实际上约等于只有一个(他其实和$[[\Bool]]$很像)
- $\P{x:\I}\P{y:\I}\eqs{x}{y}$ (这其实是$\prop{\I}$)
- 证明完了上一题就很简单了
- 假设你把他命名为$\rm{I\_eqv\_True}$
```
rw ua I_eqv_True
intro x
intro y
destruct y
destruct x
rfl
qed
```
- $\P{a:\U}\P{f:\I \ra a}\eqs{(f\ \i{0})}{(f\ \i{1})}$这题很水直接$\ap{f}{\seg}$
- 解锁了$\rm{transeq}$
- 最后$\I$这里有一个挑战,直接进去,
- 进入了之后没证完就别出来 否则卡顿极高
