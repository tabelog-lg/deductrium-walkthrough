# Deductrium 攻略第八章 同伦类型论
## 同伦类型论的介绍(前言)
- 同伦类型论介绍：类型不仅能看成命题还可以看成拓扑空间类型的值不仅可以看成证据还可处看成空间中的点
- 定义相等的值相当于同一个点命题相等的值不一定是相同的点命题相等的证据是连接这两点的“道路”
- 相等证据的相等则是连接道路的道路道路会从一维线状变成面状、体状...
- 每个点a:A都有自己到自己的平凡道路即$\:{\refl{a}}{\eqs{a}{a}}$道路的连接、逆正好对应等式的传递性、自反性
- 现在你可能会明白为什么刚才解锁的东西叫做圆周类型了因为$\loop$是个自己到自己但不是$\refl{base}$的路径它就是一个圈

## S1
- $\s{1}$是圆周类型 有一个构造子$\base$ 并且$\eqs{\base}{\base}$有一个不同于$\refl{base}$的证据$\loop$ 
- 在做真正有关$\rm{S}1$的题之前 我们可以先得到$\ind{S1}$
- 路上的题都很简单 顺便会解锁$\rm{apd}$和$\rm{trans}$
- 把$\rm{trans}$旁边的那些都给做了,你可以获得一些有用的定理(证明策略eq的证据)
- $\ind{S1}$是圆周类型$\s{1}$的依赖消去规则(归纳原理)
- 它说明:给定一个类型族$C:\rm{S}1\ra\U$
- 若要在每个点$x:\s{1}$上构造一个元素$\:{f(x)}{C(x)}$只需给出:
- 基点处的值$\:{cb}{C\ \base}$
- 一条1-路径$\:{cl}{\eqs{\trans{C}{\loop}{cb}}{cb}}$
- 则$\ind{S1}\ C\ cb\ cl$给出所需依赖函数$\:{f}{\P{\:{x}{\rm{S}1}}C(x)}$
- 其计算规则为:
- $\eqss{f(\base)}{cb}$
- $\:{\rm{apd\_loop}}{\P{\:{cl}{\eqs{(\trans{C}{loop}{cb})}{cb}}}}\eqs{\apd{(\ind{S1}\ C\ cb\ cl)}{\loop}}{cl}$
- 也就是说,圆周上的依赖函数完全由基点的值和环路运输后的粘合路径所确定
- (对于非依赖情形,可使用$\rec{S1}$,但$\ind{S1}$是更一般的形式)

看到这道门了吗
$\eqs{(\refl{\base})}{(\*{\loop}{(\inveq{\loop})})}$
不能直接证明,必须先证明一个一般性引理
$\:{\rm{right\_inveq}}{\P{\:{a}{\U}}\P{\:{x}{a}}\P{\:{y}{a}}\P{\:{m}{\eqs{x}{y}}}}\eqs{\refl{x}}{{\*{m}{(\inveq{m})}}}$
```proof
intro a
intro x
intro y
intro m
destruct m
qed
```
然后给$\rm{right\_inveq}$带入$\s{1}\ \base\ \base\ \loop$就能得到答案
获得成就:顺时针一圈逆时针一圈,还是回到原点
同时解锁等价($\rm{eqv}$)

看到这道门了吗,做完后就能解锁四个有用的证据
$\eqs{\inveq{(\inveq{\loop})}}{\loop}$
和上面的一样不能直接证明,必须先证明一个一般性引理
$\:{\rm{inv\_inveq}}{\P{\:{a}{\U}}}\P{\:{x}{a}}\P{\:{y}{a}}\P{\:{m}{\eqs{x}{y}}}\eqs{\inveq{(\inveq\ m)}}{m}$
```proof
intro a
intro x
intro y
intro m
destruct m
rfl
qed
```
然后给$\rm{inv\_inveq}$带入$\s{1}\ \base\ \base\ \loop$就能得到答案

$\P{m:\eqs{\base}{\base}}\P{n:\eqs{\base}{\base}}\left( \eqs{\*{\loop}{m}}{\*{\loop}{n}} \right) \ra \eqs{m}{n}$
依旧不能直接证明,必须先证明一个一般性引理
$\rm{compeq\_le}:\P{a:\U}\P{x:a}\P{y:a}\P{z:a}\P{p:\eqs{x}{y}}\P{m:\eqs{y}{z}}\P{n:\eqs{y}{z}}\left( \eqs{\*{p}{m}}{\*{p}{n}} \right) \ra \eqs{m}{n}$
```proof
intro a
intro x
intro y
intro z
intro p
destruct p
intro m'
destruct m'
intro n
intro h
apply h
qed
```
然后给$\rm{compeq\_le}$带入$\s{1}\ \base\ \base\ \base\ \loop$就能得到答案

$\P{m:\eqs{\base}{\base}}\P{n:\eqs{\base}{\base}}\P{o:\eqs{\base}{\base}}\eqs{\*{(\*{m}{n})}{o}}{\*{m}{(\*{n}{o})}}$
依旧不能直接证明,必须先证明一个一般性引理
是不是很眼熟

## eqv

- $\rm{eqv}$即等价$\rm{eqv}\ x\ y$简写为$x\text{~}=y$(显示为$\eqv{x}{y}$)
- 如果两个类型$a$与$b$之间存在可逆的一到一的双射$f:a\ra b$则它们等价，记作$\rm{eqv}\ a\ b$
- “f是双射”即为存在函数$g$与$h$使得$\eqs{f(g\ x)}{x}$且$\eqs{h(f\ x)}{x}$
- 所以展开$\eqv{x}{y}$的结果就是$\S{f:x \ra y}\left( \S{g:y \ra x} \P{x:x} \eqs{x}{(g (f\ x))} \right)\times\left( \S{h:y \ra x} \P{x:y} \eqs{x}{(f (h\ x))} \right)$

## 泛等公理ua
- 接下来我们要解锁ua
- $\P{a:\U}\P{b:\U}\P{c:\U}(\eqv{a}{b}) \ra (\eqv{b}{c}) \ra (\eqv{a}{c})$
```txt
intro a
intro b
intro c
expand eqv
intro h
destruct h
destruct h1
destruct h10
destruct h11
intro h
destruct h
destruct h1
destruct h10
destruct h11
ex
intro h
apply h0'
apply h0
apply h
simpl
case
ex
intro h
apply h100
apply h100'
apply h
simpl
intro x
rwb h101' (h0 x)
apply h101 x
ex
intro h
apply h110
apply h110'
apply h
simpl
intro x
rwb h111 (h110' x)
apply h111' x
qed
```
- 解锁了泛等公理$\rm{ua}$(等价即相等)
- $\rm{ua}$是命题$(\eqv{a}{b})\ra(\eqs{a}{b})$的证据,同时也是$\rm{id2eqv}$映射的逆映射
  而$\rm{id2eqv}$是命题$(\eqs{a}{b})\ra(\eqv{a}{b})$的证据,可由$\ind{eq}$得到 无需新的公理
- $\P{a:\U}\P{b:\U}(\eqv{a}{b}) \ra (\eqv{b}{a})$在有了ua之后就很简单了
```txt
intro a
intro b
intro h
apply id2eqv
apply inveq
apply ua
apply h
qed
```
- 我们解锁了全类(宇宙)层级提升操作$\rm{LiftU}$
- 同时解锁了
- $\rm{liftU}:?1\ra\rm{LiftU}?1$
- $\rm{lowerU}:(\rm{LiftU} ?1)→?1$
  
  $\P{a:\U}\P{b:\U}\eqv{(\eqv{a}{b})}{(\eqs{a}{b})}$不提升会有作用 类型不匹配错误,无法通过(类型论里的最强大的门,至今都没有拆除方法 )
  
$\P{a:\U}\P{b:\U}\eqv{(\rm{LiftU} (\eqv{a}{b}))}{(\eqs{a}{b})}$
```proof
intro a
intro b
expand 1 eqv
ex
intro h
apply ua
apply lowerU
apply h
simpl
case
ex
intro h
apply liftU
apply id2eqv
apply h
simpl
intro x
eq
rfl
ex
intro h
apply liftU
apply id2eqv
apply h
simpl
intro x
eq
rfl
qed
```
